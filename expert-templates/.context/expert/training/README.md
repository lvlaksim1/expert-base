# Стандарт профессионального развития

Текущая зафиксированная исследовательская версия — `EXPERT-TRAINING-v0.2`.

Конкретные восемь нормативных файлов не перепечатываются вручную в шаблоне. Их точные Git blob SHA закреплены в `TRAINING_BASELINE.lock.json`. При создании конкретного Эксперта `expertctl.py` получает каждый объект непосредственно из `lvlaksim1/supervisor`, проверяет Git blob SHA и сохраняет снимок в `training/specs/`.

Это исключает расхождение текста шаблона и проверенного baseline.

## Важный статус
Внутренний аудит v0.2 не обнаружил оставшихся известных критических/высоких противоречий исходного реестра, но это ещё не доказательство работы реализации. До завершения iOS-испытаний baseline остаётся исследовательским.
