# Профессиональные ресурсы

Папка хранит долговременную профессиональную основу конкретного Эксперта.

- `knowledge/` — проверенные ограниченные профессиональные утверждения;
- `skills/` — проверенные процедурные навыки;
- `methods/` — воспроизводимые профессиональные методы;
- `tools/` — сведения о проверенных инструментах, версиях, правах и границах;
- `experience/` — структурированные эпизоды, атрибуция и принятые уроки;
- `profession-map.md` — карта профессии;
- `target-professional-profile.md` — версия целевого профиля;
- `qualification-state.md` — текущее доказательное состояние и допуски.

Рабочие кандидаты G0 должны быть явно отделены от принятых G1–G4. Проектная память и сырые журналы не копируются сюда автоматически.
