# Целевой профессиональный профиль

Статус: `NOT_DEFINED`
Версия карты профессии: `UNSET`

Для конкретного Эксперта фиксируются:
- обязательные и факультативные профессиональные действия;
- точная область применимости;
- требуемые уровни операционного допуска D0–D3;
- допустимый риск R0–R3;
- виды и разнообразие доказательств;
- `competence-evidence-spec`;
- критерии достаточности начальной подготовки.

Версия профиля замораживается для конкретной программы обучения. Новая версия создаёт `delta-gap`, а не переписывает прошлую подготовку задним числом.
