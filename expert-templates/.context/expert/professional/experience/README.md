# Профессиональный опыт

Событие, эпизод и профессиональный урок — разные сущности. Проектные факты сначала записываются как эпизоды с происхождением. Обобщённый урок принимается только после проверки переносимости. Опыт менеджера проекта требует `attribution-record` и не становится прямой компетентностью родительского Эксперта автоматически.
