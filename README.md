# Expert Base

Универсальная базовая надстройка для постоянного профессионального агента **Эксперт**.

`expert-base` не содержит знаний конкретной профессии. Он добавляет к `service-agent-base` профессиональную идентичность, защищённую основу, модель профессиональных ресурсов, структуру обучения, квалификации и накопления опыта.

## Архитектура наследования

```text
service-agent-base
        ↓
    expert-base
        ↓
  конкретный Expert
        ↓
Project Managers, созданные из версии его профессиональной основы
```

Текущая исследовательская версия: `0.1.2-research`.

## Зафиксированная основа

- Service Agent Base: `lvlaksim1/service-agent-base@2a03aaf14fdd79612acefe8c5ac22600e5d3b57b`; эта версия прошла CI и устанавливает/ремонтирует обязательный `.context/EXECUTION_INVARIANTS.md`.
- Стандарт профессионального развития: `EXPERT-TRAINING-v0.2` из `lvlaksim1/supervisor`, точные SHA находятся в `expert-templates/.context/expert/training/TRAINING_BASELINE.lock.json`.
- Поведенческий слой `expert-templates/.context/expert/EXECUTION_INVARIANTS.md` обязателен при каждом восстановлении Эксперта: наличие правила в памяти не считается доказательством его применения; критичные правила проходят предвыходную проверку.
- Проект следующей нормативной версии `EXPERT-TRAINING-v0.3-DRAFT-DELTA.md` формализует это требование, но не подменяет переаудированный baseline v0.2 до завершения нового аудита.
- PP-RM — единственный учитываемый механизм длительного обучения в текущей версии.
- GitHub — устойчивый носитель состояния, доказательств и профессиональных ресурсов.
- ND-RM и ChatGPT Library в текущую версию не входят.

## Статус

Это **исследовательская база**, а не окончательно утверждённый стандарт. Внутренние противоречия baseline v0.2 прошли повторный аудит, но реальные испытания на профессии iOS и часть реализационных гарантий ещё не выполнены.

## Создание конкретного Эксперта

1. Создать постоянного служебного агента из зафиксированной версии `service-agent-base`.
2. Применить Expert-надстройку командой `python installer/expertctl.py apply --target <repo> --expert-id <id> --specialization <name>`.
3. Сформировать и утвердить профессиональный профиль и карту профессии.
4. Провести исходную диагностику и только затем начинать профессиональное обучение.

Проектная память не переносится в Эксперта автоматически. Любой импорт опыта другого агента проходит классификацию, проверку происхождения и процедуру принятия профессиональных ресурсов.
